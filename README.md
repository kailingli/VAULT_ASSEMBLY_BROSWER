# VAULT_ASSEMBLY_BROSWER (English and Simplified Chinese)
A zero-dependency local web STL file navigator and PDF guide viewer for the VAULT modular 3D-printed storage system.
专为 VAULT 模块化 3D 打印收纳系统打造的本地网页版 STL 文件检索与 PDF 组装指南查看工具，完全零依赖。

## Quick Start
快速上手

1. Clone or download this repository.
克隆或下载本代码仓库。
2. Place `index.html` inside your root `VAULT_USSA` folder alongside the `01. DRAWERS` directory and PDF manuals
将 index.html 放置在您的 VAULT_USSA 根目录下，与 01. DRAWERS 文件夹以及各 PDF 说明书存放在同一级目录。
3. Double-click `index.html` to open it in any modern browser (Chrome, Safari, Edge, Firefox).
双击 index.html 即可在任意现代浏览器（Chrome、Safari、Edge、Firefox 等）中打开。
4. Select your module size under **Component Finder** or reference assembly diagrams under **Assembly Manuals**.
在“组件查找器”中选择您的模块规格尺寸，或在“组装说明书”标签下查阅对应的装配图纸。
